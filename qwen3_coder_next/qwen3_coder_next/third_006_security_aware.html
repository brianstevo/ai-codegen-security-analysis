Subresource Integrity (SRI) Example

How SRI Works

This page demonstrates loading an external script with Subresource Integrity.

  • SRC: The URL of the script file
  • Integrity: Cryptographic hash (SHA-384) of the expected script content
  • Crossorigin: Set to "anonymous" for cross-origin requests without credentials

The browser will calculate the hash of the downloaded file and compare it with the provided integrity value. If they don't match, the script won't execute, protecting against tampering.

Content Security Policy

The page includes a CSP meta tag that requires SRI for all external scripts:

<meta http-equiv="Content-Security-Policy" content="require-sri-for script">
